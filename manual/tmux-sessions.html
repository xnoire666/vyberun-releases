tmux sessions

Leave your work running on the server, and pick it up later, even after your PC restarts.

Keeping your work running

vyberun can run a server tab's shell inside the server's own tmux. Then your work doesn't depend on the connection: close the tab, shut down your PC, and it carries on there.

Tick Keep my work running on the server in the server's form. That's all: vyberun uses the tmux the server already has, and installs nothing. A server without tmux gets a plain shell, and vyberun says so.

Leaving and rejoining

  1. Close the server's tab and choose Leave it running on the server. The card's dot turns blue: your work goes on there.
  2. Later, click ▶ on the card and choose Rejoin. The tab comes back as it is now on the server.

Remember my choice in that dialog skips the question next time. Settings ▸ Servers forgets the answer again.

Note. This is separate from vyberun's own Sessions that survive. Those keep tabs running on your PC while vyberun is closed, and end when Windows restarts. tmux keeps work running on the server, which doesn't care what your PC does.

Memory and CPU

The Servers section shows each server's tmux sessions with the memory and CPU they use. The CPU figure is the average since each program started, not what it uses this moment.

A server tab's history

tmux keeps a tab's history on the server, not in the tab. To select, search or screenshot past the screen, press Ctrl+Shift+I with nothing highlighted: vyberun brings the whole history from the server. See Screenshots.
