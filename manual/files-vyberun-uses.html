Files vyberun uses

Where vyberun keeps your settings, logs and saved passwords.

The settings folder

Everything vyberun remembers is in one folder. Where it is depends on how vyberun was installed:

InstalledThe settings folder
The zip%LOCALAPPDATA%\vyberun
The Store version, on a PC that had the zip before%LOCALAPPDATA%\vyberun, the same folder the zip used
The Store version, on a PC that never had vyberunInside the Store version's own folder: %LOCALAPPDATA%\Packages\Paraxord.vyberun_y91868xpbp6my\LocalCache\Local\vyberun

The Store version always sees its folder as %LOCALAPPDATA%\vyberun. On a PC that never had vyberun, Windows keeps that folder inside the app's own folder, and removes it when the app is uninstalled. Help ▸ Open vyberun's settings folder opens it from the zip; for the Store version, paste the path from the table into File Explorer.

In itWhat it holds
settings.json and the .txt filesYour settings, one value each
spaces.json, projects.json, servers.jsonYour spaces, cards and servers (not their passwords)
tabs.jsonThe tabs that are open, so they come back
saved-agents.jsonYour saved agents (Settings ▸ Agents)
extensionsThe extensions you added
vyberun.log, session-host.logThe logs (see Logs)
session-hostA copy of the background program that keeps tabs running
agentsThe zip version's tools for Claude Code (the Store version's are part of the app)

Warning. Change settings in vyberun, not in these files. vyberun keeps its settings in memory and writes them all back on the next change, so an edit made while it runs is lost. If you must edit a file, close vyberun first.

To move to another PC, copy the folder while vyberun is closed on both. Server passwords don't move with it: enter them again.

Note. Moving from the zip to the Store version keeps your spaces, cards, servers and settings: the Store version finds them in %LOCALAPPDATA%\vyberun, where the zip left them, and doesn't start as a first install. To start afresh, close vyberun with Stop everything and rename that folder (to vyberun.old, for example) before starting it; rename it back to return to your old setup.

Claude Code's settings

When you choose Fix for "Claude works with your vyberun tabs" in the Claude Code checklist, vyberun adds two things to Claude Code's own settings, for every project:

  • Its tools, named vyberun, in %USERPROFILE%\.claude.json (claude mcp list shows them).
  • Four hooks in %USERPROFILE%\.claude\settings.json: session-start, prompt, may-send and sent, each running vyberun-agents.exe.

They point at the zip's copy in the settings folder's agents, or, for the Store version, at %LOCALAPPDATA%\Microsoft\WindowsApps\vyberun-agents.exe, a command the Store version adds to Windows. Outside a vyberun tab they do nothing. A copy of what was there before is kept beside each file (.vyberun-backup).

Saved passwords

When you tick Remember it under a server's password, vyberun keeps it in Windows Credential Manager, not in a file. The entry is named vyberun server …. Open Credential Manager ▸ Windows Credentials to see or remove it.

The program folder

The zip version runs from the folder you unzipped it into, and nothing in that folder changes while you use it. That's why you can unzip a new version over it. The Store version is installed by Windows in a protected folder.

A separate data folder

The environment variable VYBERUN_DATA points vyberun at another folder instead of %LOCALAPPDATA%\vyberun, for a test or demo copy that mustn't touch your real settings. Give such a copy its own program folder too: copies of vyberun from the same folder share one background program, and so the same tabs.
