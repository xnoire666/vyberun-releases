Copy, paste and links

Copy and paste text, paths and pictures, and open links and files from the terminal.

Copy and paste

KeysDoes
Ctrl+Shift+CCopies the highlighted text
Ctrl+VPastes
Right-clickCopies the highlighted text, or pastes when nothing is highlighted
Ctrl+right-clickOpens the terminal's menu: copy, paste, split, screenshot and more

Drag to highlight text. To swap what right-click and Ctrl+right-click do, go to Settings ▸ Terminal ▸ Mouse ▸ Right-click in a terminal.

Tip. Typed too much? Highlight part of the line you're typing and press Backspace or Delete: all of the highlighted part goes at once.

Pasting a file's path

  • Copy a file in File Explorer, then press Ctrl+V in the terminal: its full path is typed for you.
  • Or drag files from File Explorer onto the terminal.

In Git Bash and Ubuntu, a Windows path such as C:\Users\dev\notes.txt goes in the way that shell writes it, /c/Users/dev/notes.txt, since bash drops backslashes.

Pasting a picture

Take a screenshot with the Snipping Tool (Win+Shift+S), then press Ctrl+V in the terminal. vyberun saves the picture as an image file and types its path, so a program such as Claude Code can open it.

Opening links and files

Hold Ctrl and click a link or a file path in the terminal:

  • A link opens in your browser.
  • A code or text file opens in your editor, at its line where the editor can. Choose the editor in Settings ▸ Projects ▸ Open projects in.
  • Other files open in the app Windows uses for them.
