Using extensions

Extensions add their own spaces, menus and services to vyberun.

What an extension is

An extension teaches vyberun about a kind of work: for example a space that lists your Docker Compose stacks, or one that shows what's listening on which port. It can add its own space to the sidebar with cards, buttons and menus, its own menu in the menu bar, and run things in vyberun's terminal.

Extensions add to vyberun. They never change vyberun itself.

Turning them on and off

Open Extensions ▸ Manage extensions…. It lists what's installed, with any problem loading one. Turn each on or off any time: its part of vyberun comes and goes right away.

To hide an extension's space without turning it off, use Settings ▸ Sidebar.

Adding one someone shared

  1. Extensions ▸ Manage extensions… ▸ Add .zip… (or Add folder…).
  2. vyberun shows who made it and asks before running it.

Warning. An extension runs code with your rights, like any program you install. Only turn on extensions you trust.

Where they're kept

Extensions ▸ Open my extensions folder opens the folder extensions are added to. Removing an extension in Manage extensions… removes it from there.

If an extension stops working or vyberun reports a problem with it, turn it off in Manage extensions…: vyberun keeps running either way, and writes the extension's errors to its log (see Logs).
