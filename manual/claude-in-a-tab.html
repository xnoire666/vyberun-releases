Claude in a tab

vyberun is made for working with Claude Code. Start it in a tab and vyberun follows what it does.

Starting Claude

  1. Open a project's card.
  2. Type claude in its tab and press Enter.

Claude Code starts in that folder, and keeps running when you close vyberun (see Sessions that survive). vyberun doesn't install Claude Code or sign you in: install it as Anthropic describes, once, and it works in any tab.

Setting it up for vyberun

A few Claude Code settings make it work better inside vyberun: the mouse, copying, screenshots, and vyberun's tools for reading tabs.

  1. Open Settings ▸ Claude Code ▸ Open the checklist….
  2. Choose Fix next to anything that isn't set.
  3. Start Claude again in the tabs where it was already running. Claude Code reads its settings and tools when it starts.

Seeing what Claude does

You can tell what each Claude is doing from any tab:

  • A dot blinks on its tab while Claude works.
  • An amber ! shows when Claude waits for you: a question or a permission request.
  • When it finishes while you're elsewhere, its line in the sidebar blinks green until you open it. In a folded space, the space's name blinks.

In the sidebar, a card's tabs are listed under it: ✳ for a Claude tab, >_ for a shell, then the tab's name and its role. Click a line to go to that tab. When vyberun isn't in front, Windows tells you when Claude needs you or has finished (see Notifications and activity).

Showing Claude something from another tab

An error in a server's tab or a build? Give it to Claude without copying:

  1. Highlight the lines, then Ctrl+right-click ▸ Show selection to an agent. Or right-click the tab ▸ Show to an agent for its last command or last lines.
  2. Pick an agent tab: Claude Code, Gemini CLI, Codex or Aider.
  3. The text lands in that agent's prompt, with where it came from. Nothing is sent until you press Enter, so add your question first.

To let Claude look around a broken tab itself, see Reading other tabs.

Moving a conversation

A Claude conversation belongs in another tab or card? Right-click its tab ▸ Move Claude to… and pick where. The conversation moves, not the terminal: it's resumed there, with its role.

Finding and capturing

  • Ctrl+Shift+F in a Claude tab searches its whole conversation, even what's long gone from the screen. See Find and search.
  • Ctrl+Shift+K captures a long answer as one picture. See Screenshots.

Other agents

vyberun recognises Claude Code best: its state, its conversation, its tools. Other command-line agents such as Gemini CLI, Codex and Aider run in tabs like any program, can be given a role, and can be shown text from other tabs. Messages between agents, handovers and reading tabs are Claude Code only for now.
