Installing

Get vyberun from the Microsoft Store, or use the zip.

There are two ways to get vyberun. They're the same program.

Microsoft StoreZip
.NETIncludedInstall the .NET 10 Desktop Runtime once
UpdatesAutomaticUnzip the new version over the old one
SignedYes, by MicrosoftNo: Windows may warn you the first time
Where it runs fromInstalled by WindowsAny folder you choose

From the Microsoft Store

  1. Open vyberun in the Microsoft Store and choose Get.
  2. Start vyberun from the Start menu.

You can also install it from a terminal: winget install 9MX9G62RFFQ5.

From the zip

  1. Install the .NET 10 Desktop Runtime (x64), once per PC. If it's missing, Windows offers the download when vyberun starts.
  2. Download the latest vyberun-<version>-win-x64.zip from Releases.
  3. Unzip it to a folder that stays, for example C:\Tools, and run vyberun\vyberun.exe.

Warning. The zip isn't signed. If Windows shows "Windows protected your PC", choose More info, then Run anyway. If Smart App Control is on, Windows may block the zip's vyberun altogether: use the Store version instead.

Each release lists a SHA-256 checksum for its zip, so you can check the download.

Tip. Don't run vyberun from your Downloads folder. Downloads tends to get cleaned up, and each vyberun folder keeps its own tabs (see Common problems).

The first start

The first time vyberun starts, Help opens on a one-minute tour. You can open it again any time from Help ▸ How to use vyberun.

Then add the folder you work in: click + next to General in the sidebar ▸ Add folder…, or drag the folder from File Explorer onto the sidebar. It becomes a card. Click the card and a terminal opens in that folder.

Where your settings live

Your settings, spaces, cards and servers are kept in %LOCALAPPDATA%\vyberun, not in the program's folder, so updating vyberun keeps them. Help ▸ Open vyberun's settings folder opens it. Saved server passwords are kept in Windows Credential Manager. See Files vyberun uses for the details.
