Logs

vyberun writes down what it does, so a problem can be traced.

The logs are plain text files in vyberun's settings folder (see Files vyberun uses). They record what vyberun did and when.

vyberun.log

Help ▸ Open vyberun's log opens it. It records starts and restarts, screenshots, servers, agents and Activity, each line with its time. When something goes wrong, the lines just before it usually say why.

session-host.log

The background program that keeps your tabs running writes its own log, session-host.log, in the same folder. It's the one to read when tabs didn't survive:

  • stopping everything: vyberun asked it to stop all tabs (Stop everything, or the Closing vyberun setting).
  • connected, 0 kept right after a start: no tabs were running, for example after Windows restarted.
  • connected, 4 kept: vyberun found 4 tabs still running and brought them back.

When vyberun crashed

If vyberun closed by itself, Windows records it too: open Event Viewer ▸ Windows Logs ▸ Application and look for an Application Error for vyberun.exe at that time. Its details, together with the last lines of vyberun.log, are what's needed to fix it. See Reporting a problem.
