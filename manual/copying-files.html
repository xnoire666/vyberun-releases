Copying files

Copy files to and from a server without leaving the terminal.

From a server

  1. Hold Ctrl and click a file's name in the server's tab. File names are underlined while Ctrl is held.
  2. vyberun checks with the server that it's a file, then offers where it goes: the place your last download went (first in the list: Enter takes it), a local tab (into the folder it's in), Downloads, or any folder.

A highlighted path works too: Ctrl+right-click ▸ Download to.

To a server

  • Drop files on the server's tab. They go into the folder that tab is in.
  • Or Ctrl+right-click in the server's tab ▸ Upload a file here….
  • Or, in a local tab, highlight a file's name and Ctrl+right-click ▸ Upload to ▸ a server. It goes into the folder that server's tab is in, or, with Choose a server…, its home folder.

Folders can't be uploaded as they are: right-click the folder in File Explorer ▸ Compress to ZIP and drop the zip.

When a file of that name is already there, vyberun asks: keep both (the new one saved as name-1) or replace it. On a production server, every upload asks first.

While it copies

A line under the terminal shows the progress, with Pause and Cancel.

  • If the connection drops, what's copied so far is kept, and vyberun tries again by itself, carrying on from there.
  • A resumed copy is checked against the original (SHA-256) before it gets its name, so a file is never half right.
  • Closed vyberun in the middle of a copy? It's offered again when vyberun starts: Resume or Discard.

Copies sign in the same way as the server's tabs: its key or its remembered password.
