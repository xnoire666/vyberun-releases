Keys and PuTTY sessions

Sign in to servers with a key file or the sessions you saved in PuTTY.

Key files

Under Sign in with, choose Key file, then Browse… to the key. vyberun takes:

  • .pem and OpenSSH keys, as most cloud providers and ssh-keygen make them.
  • .ppk keys, PuTTY's own format. These need PuTTY installed, since vyberun signs in with them through PuTTY's plink.

A key stays where it is: vyberun remembers its path and reads it when it connects.

Keys with a passphrase

vyberun connects without asking you questions, so a .ppk key with a passphrase needs converting once:

  1. Open it in PuTTYgen. The server's form has an Open in PuTTYgen button.
  2. Choose Conversions ▸ Export OpenSSH key and save it next to the .ppk.
  3. Browse… to the new key in the server's form.

PuTTY sessions

If you've saved sessions in PuTTY, vyberun can use them:

  • The PuTTY button next to + in Servers brings in all of them at once, one card each.
  • Or add one server: under Sign in with, choose PuTTY session and pick it. Its address, user and key come from PuTTY.

Some sessions don't keep everything vyberun needs:

  • No user name: fill in User. Tabs and file copies sign in as that user.
  • No address: type the host, user and key under Key file instead.

Opens in chooses where a PuTTY session's server opens: a vyberun tab, or Ask each time. ⋯ on its card ▸ Open in PuTTY opens it in PuTTY's own window.

When signing in fails

  • "login as:" in a copy or a tab: the PuTTY session has no user name. Fill in User in the server's form.
  • Permission denied: the server doesn't accept that key or user. Check them with ssh -i <key> <user>@<host> in a PowerShell tab.
  • See Common problems for copies that stop with "Cannot answer interactive prompts".
