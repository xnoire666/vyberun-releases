Manual › Servers

Adding a server

Your servers in the sidebar, one click from a terminal on them.

Adding a server

  1. Click + next to Servers in the sidebar.
  2. Fill in Name, Host, Port and User (such as deploy or admin).
  3. Under Sign in with, choose Key file, Password or PuTTY session. See Keys and PuTTY sessions.
  4. Choose Save. The server becomes a card in Servers.

To change it later: ⋯ on its card ▸ Edit. Server cards can be moved into your own spaces like any other card.

Signing in with a password

Type it in the Password box and tick Remember it. When the server asks for it, vyberun types it for you. It's kept by Windows Credential Manager, never in vyberun's files.

Leave the box empty to type the password yourself in the tab each time.

Connecting

Click ▶ on the server's card. A tab opens on the server, and the card's dot turns green.

DotMeans
GreenConnected
BlueYour work is still running on the server, with no tab open (see tmux sessions)
RedThe connection was lost. Press Enter in the tab to connect again.
GreyNo tab open

Split a server tab (Ctrl+Shift+D and the other split keys) and the new pane connects to the same server, in the folder you were in.

Production servers

Tick Production server when adding one. Its card and tabs are marked PROD, so you always know where you are. vyberun is more careful there too: an upload asks first, and agents always ask before reading or investigating its tabs.

Snippets

Save the commands you run often on a server: ⋯ on its card ▸ Snippets. Write {name} in a snippet and vyberun asks for that value each time it runs, for example tail -n 200 /var/log/{service}.log.

What vyberun changes on a server

Nothing. vyberun connects over SSH like any other client and uses only what's already there: the shell, and tmux if the server has it. It never installs anything or changes the server's settings.

Settings

Settings ▸ Servers can forget every remembered password, and every "Remember my choice" answer (what closing a server's tab does, and where a PuTTY server opens), so you're asked again.
