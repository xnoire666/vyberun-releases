Making one

Make your own extension by describing it to Claude Code. No C# needed.

What you need

  • The .NET 10 SDK to build it. dotnet --version should say 10.
  • A coding agent such as Claude Code, to write it for you. You can also write the C# yourself.

Making one

  1. Extensions ▸ Manage extensions… ▸ New extension…. Give it a name and choose Create. vyberun makes a ready-to-build folder and opens a terminal tab in it.
  2. Type claude and describe what it should do (an example follows).
  3. Claude writes it and builds it. The build installs it into your extensions folder by itself.
  4. Restart vyberun (File ▸ Restart vyberun, or Ctrl+Shift+F5) to load it. The first time, vyberun asks whether to turn it on.

For example, in step 2:

Make this extension a "Ports" space in vyberun's sidebar: one card per TCP port something is listening on, with the program's name. Each card's menu: Open in browser, Copy URL, and Stop process (ask first). Refresh every 10 seconds.

The folder has a CLAUDE.md with the rules and the commands, which Claude reads before it writes anything, so what it builds stays within the rules.

Changing it

Tell Claude what you'd like different, let it build, then restart vyberun again. vyberun loads an extension's code once, so restart after every build.

Extensions ▸ Manage extensions… shows any problem loading it, and vyberun's log has the extension's own lines and errors.

Sharing it

Zip its folder, with its extension.json. Someone else adds it with Manage extensions… ▸ Add .zip…, and vyberun shows them who made it before it runs.

The developer guide

The extension developer guide explains the parts of the API, the rules every extension follows, and a ten-minute tutorial that builds the Ports extension above step by step. vyberun has it too: Help ▸ Extension developer guide.
