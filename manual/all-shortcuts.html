All shortcuts

Every key in vyberun, on one page.

vyberun shows the same list in Help ▸ All shortcuts.

Everywhere

KeysDoes
Ctrl+Shift+PSearch files, folders and everything in vyberun
Ctrl+,Settings
Ctrl+Shift+RRecent cards, newest first: hold Ctrl+Shift, tap R to go down, let go to open
Ctrl+Shift+BShow or hide the sidebar
F11Full screen
Ctrl+Shift+F5Restart vyberun (tabs keep running)
Ctrl+dragMove the window from anywhere in it, when it isn't maximized
Ctrl+scroll over the sidebarMake the sidebar bigger or smaller

In the search

KeysDoes
TabSwitch between Files and vyberun
% or *Anything in between: cust%test finds CustomerTest.php
EnterOpen it: a file in its app, a folder in File Explorer. On a setting, switch it.
Shift+EnterFiles and folders: a new terminal there
Ctrl+EnterFiles: show it in File Explorer
EscLeave the search

Tabs, panes and groups

KeysDoes
Ctrl+Shift+W A S DSplit up, left, down, right
Alt+arrowsMove between panes
Ctrl+Shift+ZZoom a pane, or a group's tile, and back
Ctrl+Shift+QClose a pane
Ctrl+Shift+XDetach a tab (it keeps running)
Ctrl+click tabsPick the tabs for a group
Ctrl+Shift+GGroup them: one group tab, its tabs side by side

In a tab

KeysDoes
Ctrl+Shift+FFind in this tab, or in a whole Claude Code conversation
Ctrl+Shift+CCopy
Ctrl+VPaste
Ctrl+↑ / Ctrl+↓Jump between commands (Git Bash, Ubuntu)
Ctrl+Shift+OCopy one command's output
Ctrl+= / Ctrl+- / Ctrl+0Text bigger, smaller, back to the default
Ctrl+clickOpen a link or file path
EnterIn a server tab whose connection ended: connect again

Screenshots

KeysDoes
Ctrl+Shift+IA screenshot of the selection
Ctrl+Shift+KA long screenshot. In Claude Code: once at its start, again at its end (twice: just what's highlighted)
P H R O E CIn the preview: pen, highlighter, box, circle, eraser, crop
Ctrl+C / Ctrl+SCopy it / save it
Ctrl+ZUndo the last mark or crop
V or Ctrl+dragMove around a picture larger than the window
Ctrl+= / Ctrl+- / Ctrl+0 / Ctrl+1Zoom in, out, fit the window, actual size
EscClose the preview
