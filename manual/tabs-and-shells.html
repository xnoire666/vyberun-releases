Tabs and shells

Each card has its own tabs, in the shell you like.

Opening a tab

  1. Click + above the terminal. A new tab opens in the card's folder, in your default shell.
  2. For another shell, click the small arrow next to + and choose Git Bash, PowerShell, Command Prompt or Ubuntu.

Terminal ▸ New tab offers the same, and PowerShell as administrator. That one opens in its own window, after Windows asks: a tab inside vyberun can't run as administrator.

Shells

ShellWhat it needs
PowerShellNothing: it comes with Windows.
Command PromptNothing.
Git BashGit for Windows.
UbuntuWSL with Ubuntu: wsl --install in an administrator PowerShell.

To choose the shell new tabs open, go to Settings ▸ Terminal ▸ New tabs ▸ Shell. It's used by +, by a project's first tab and by Open in Terminal. The arrow next to + still offers the others.

Naming, moving and colouring tabs

  • Rename: double-click the tab and type a name.
  • Move: drag the tab along the tab row.
  • Colour: right-click the tab ▸ Color. Mark a server tab red or a Claude tab purple, for example. The colour stays after a restart.
  • Role: right-click the tab ▸ Set role…. A role tells an agent in that tab what it does, such as "Tester: checks against the ticket".

A tab's dot shows its state: a command is running, an agent is working, it's waiting for you, or it has finished.

Closing a tab

Click the tab's ✕. A program still running in it is ended the normal way first, as Ctrl+C would.

The ✕ is easy to hit by accident. Turn on Settings ▸ Terminal ▸ Closing a tab ▸ Ask before closing a tab and vyberun asks first: close it, keep it running out of sight, or cancel. To put a tab away without closing it, see Sessions that survive.

Text size

KeysDoes
Ctrl+=Bigger text
Ctrl+-Smaller text
Ctrl+0Back to the default size

View ▸ Terminal text size and Settings ▸ Terminal ▸ Text do the same.

Long commands

When a command that ran over 10 seconds finishes while you're in another tab or another program, Windows shows a notification. Turn it off in Settings ▸ Terminal ▸ Long commands.

Moving around the history

In Git Bash and Ubuntu, vyberun knows where each command starts:

  • Ctrl+↑ and Ctrl+↓ jump to the previous or next command.
  • Ctrl+Shift+O copies one command's output.

Both are in the Terminal menu too.
