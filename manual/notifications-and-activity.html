Notifications and activity

See what's working, what needs you, and what it costs.

A tab's state

Each tab, in the tab row and in the sidebar, shows how it's going:

ShownMeans
AmberWaiting for you: an agent asks a question or needs your permission
Accent colourWorking: an agent or a command is busy
GreenFinished while you were elsewhere
RedFailed
NothingIdle

An agent counts as working while it waits on a long command or on its own background agents too. Each space's header sums up its cards, most pressing first, such as "1 waiting · 2 working".

Notifications

When something needs you while you're in another tab or another program, Windows shows a notification, and vyberun's taskbar button flashes until you come back:

  • A Claude needs you, or has finished, with how long it worked.
  • One of Claude's subagents has finished.
  • A command that ran over 10 seconds has finished or failed. Turn this off in Settings ▸ Terminal ▸ Long commands.
  • Claude tabs stopped messaging each other, because they kept going without you (see Roles and handovers).

Windows' own notification settings (Settings ▸ System ▸ Notifications) decide whether and how they show, as for any program.

Memory and CPU

Next to the tabs, vyberun shows the memory and CPU used by itself and everything in its tabs, read every few seconds. It turns amber when this PC is low on memory.

Activity

Click the memory and CPU, or choose Terminal ▸ Activity…. It lists everything running in vyberun's tabs:

  • Each pane's Claude Code, command, service or shell, with its memory, its CPU now, and how long it's been running.
  • Programs left running after their tab closed, such as a dev server an agent started in the background.
  • vyberun's own share, apart.

Go to opens that tab. Stop ends one, the way Ctrl+C would, and the tab stays open. Stop all ends everything listed. A Claude tab that has been idle for a long time is marked, so you can stop the ones you've finished with.
