Reading other tabs

Let Claude read your other tabs, or investigate a broken one, with your permission.

Reading a tab

With vyberun's tools set up (see Claude in a tab), a Claude can see your tabs and read one. Just ask: "read the api tab" or "what's the error in the build tab?". Claude doesn't have to be told which tab is which: it can list them with their names, cards and roles.

Reading never types anything into the tab. Every read is written to vyberun.log.

Note. Claude Code loads its tools when it starts. A Claude started before vyberun set them up can't read tabs until you start it again in its tab.

Who decides

Settings ▸ Agents ▸ Reading other tabs:

ChoiceReading a tab
Ask every timeEvery read asks: Allow once or No.
Ask once per tabThe first read of a tab asks. Always for this tab lasts until vyberun closes. The default.
This PC's tabs freelyTabs on this PC are read without asking. A server's tab asks once per tab.
All tabs freelyEvery tab is read without asking, server tabs too.

A production server's tab asks every time, whatever you choose.

Letting an agent investigate

Something broken in a tab, such as a server, a dev server or a build? Let an agent look into it:

  1. Right-click the tab ▸ Let an agent investigate ▸ pick a Claude Code tab.
  2. The agent gets the tab's output, then reads it without asking, and runs commands that only look: a log, a service's status, a folder, git's state. Each command shows in the tab as it runs.
  3. A command that changes something, or stopping what runs there, shows you a dialog first with the agent's reason. You can change the command, allow it, or refuse.
  4. A bar above the terminal says who is investigating. Done on it ends that. Closing either tab ends it too.

On a production server's tab, every command asks, and nothing that changes something runs there.

What reading can't do

  • An agent can't type into a tab it reads. Only an investigation runs commands, and only as described above.
  • A Claude proves which tab it's in with a key of its own, so one tab's Claude can't pretend to be another's.
  • Text read from a server or a terminal is never put into a command unchecked.
