Updating and uninstalling

Keep vyberun up to date, or remove it and its settings.

Which version you have

Help ▸ About vyberun shows the version. Every release and what changed in it is on the Releases page.

Updating the Store version

The Microsoft Store updates vyberun by itself. To update now, open the Store's Downloads page and choose Get updates.

Warning. An update closes vyberun, including the background program that keeps your tabs running, so tabs that were running end. Finish or save what's running before you update.

Updating the zip

  1. Download the new zip from Releases.
  2. Close vyberun. Choosing Keep running is fine: your tabs keep running while you update.
  3. Unzip the new version over the old one, into the same folder, replacing the files.
  4. Start vyberun. Your tabs, settings, spaces and servers are as they were.

Note. Unzip into the same folder as before. vyberun in a different folder has its own background program, so it wouldn't show the tabs the old folder's vyberun kept running.

Moving from the zip to the Store version

  1. Close the zip's vyberun with Stop everything: tabs it kept running don't move to the Store version.
  2. Install the Store version, from the Microsoft Store or with winget install vyberun.
  3. Start it. It finds your spaces, cards, servers and settings where the zip left them. If you had set vyberun up for Claude Code, the Store version moves that setup to its own tools by itself.
  4. Delete the zip's folder.

Uninstalling

  1. Close vyberun. In the close dialog, choose Stop everything, so nothing keeps running.
  2. Remove the program: - Store version: right-click vyberun in the Start menu ▸ Uninstall. - Zip: delete the folder you unzipped it into.
  3. To remove your settings too, delete %LOCALAPPDATA%\vyberun if it's there. The Store version installed on a PC that never had vyberun keeps them inside its own folder instead, and Windows removes them with it (see Files vyberun uses).
  4. To remove saved server passwords, open Windows Credential Manager ▸ Windows Credentials and remove the entries named vyberun server ….
  5. If you set vyberun up for Claude Code (the checklist's Fix), take that out of Claude Code too, or Claude Code reports a failed hook at every start: - Run claude mcp remove --scope user vyberun. - In %USERPROFILE%\.claude\settings.json, delete the four hooks that run vyberun-agents.exe, and leave the rest of the file as it is.

Uninstalling doesn't touch your projects or your servers.
